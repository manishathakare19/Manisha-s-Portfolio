## 🚀 About The Project

This is a fully responsive personal portfolio website built to showcase my projects, skills, and professional journey. It is designed with a **dark theme** and **purple neon accents**, featuring unique interactive elements.

### ✨ Key Features

- **⚛️ React.js Powered:** Built with a modern component-based architecture.
- **💻 Terminal-Style About Section:** A unique, coder-focused bio design that mimics a VS Code terminal.
- **📩 Terminal Contact Form:** A functional contact page styled like a Linux command line, integrated with **Formspree** for real-time emails.
- **📱 Fully Responsive:** Optimized for desktops, tablets, and mobile devices.
- **🎨 Dynamic UI:** Includes particle effects, typing animations, and hover interactions.

## 🏁 Getting Started

If you want to run this project locally on your machine, follow these steps.

### Prerequisites

- **Node.js** (Installed on your machine)
- **Git**

### Installation

1.  **Clone the repository**

    ```bash
    git clone [https://github.com/YOUR-USERNAME/Portfolio.git](https://github.com/YOUR-USERNAME/Portfolio.git)
    ```

2.  **Navigate to the project directory**

    ```bash
    cd Portfolio
    ```

3.  **Install dependencies**

    ```bash
    npm install
    ```

4.  **Run the application**
    ```bash
    npm start
    ```
    The app will open automatically at `http://localhost:3000`.
